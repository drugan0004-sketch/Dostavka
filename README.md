# FastDeliveri

Краткое описание: Это консольное приложение доставки еды .


## 🛠 Стек технологий
*   **Язык:** C++17 (или ваша версия)
*   **Система сборки:** CMake / Makefile
*   **Компилятор:** GCC / Clang / MSVC

## 📦 Установка и сборка

### Требования
Убедитесь, что у вас установлены:
*   CMake (версии 3.10+)
*   Компилятор с поддержкой C++17

### Сборка
```bash
# Клонирование репозитория
git clone https://github.com
cd название-проекта

# Создание директории сборки
mkdir build && cd build

# Конфигурация и компиляция
cmake ..
make
```
